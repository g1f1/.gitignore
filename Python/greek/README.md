`pycache/`: Περιέχει τα byte-compiled αρχεία Python, τα οποία δημιουργούνται αυτόματα από την Python για επιτάχυνση της εκτέλεσης.

`*.py[cod]`: Περιέχει τα byte-compiled αρχεία Python (`.pyc`, `.pyo`, `.pyd`), τα οποία δημιουργούνται αυτόματα από την Python.

`*$py.class`: Περιέχει τα compiled αρχεία από Jython.

`*.so`: Περιέχει τα compiled C extensions.

`.Python`: Περιέχει την Python εγκατάσταση.

`*.mo`, `*.pot`: Περιέχουν αρχεία μεταφράσεων.

`.ipynb_checkpoints`: Περιέχει τα checkpoints των Jupyter Notebooks.
